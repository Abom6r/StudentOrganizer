# 📱 Student Organizer AI

An intelligent academic productivity mobile application designed to help students organize their studies, manage tasks, collaborate with classmates, and improve academic performance using **Artificial Intelligence**.

Built using **Flutter + Dart + Supabase + Gemini AI**, the app combines smart scheduling, task management, study collaboration, and AI-powered planning into one modern platform.
